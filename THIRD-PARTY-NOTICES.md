# Source and license status

Original addon runtime code, tests, tooling and documentation were prepared for MoobStack. **No software license has been selected for this new repository.** No MIT/GPL grant or copied license file is included. Free distribution and visible code are project requirements; they do not by themselves establish an open-source redistribution license.

Blizzard UI/API definitions were inspected for compatibility. No extracted Blizzard Lua source, fonts, music or other game binaries are bundled. Runtime icon, font and texture paths refer to assets already supplied by the client.

CMaNGOS Classic data was consulted as reference evidence for material IDs, probability values and quantity facts. The package uses an original compact representation of those observations and identifies them as unverified Classic estimates for Forever. It does not distribute the SQL database, its executable code or its license as the addon's own license.

The Lua interpreter compiled for development and third-party research downloads are not release assets. The runtime requires none of them. No Auctionator implementation or libraries are included.

If a license is selected before publication or additional third-party code/assets are added, update the license, notices and release documentation together.
