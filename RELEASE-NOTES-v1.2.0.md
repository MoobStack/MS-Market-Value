# MS Market Value 1.2.0

Market opportunities, better crafting prices and a personal gold ledger for WoW Forever.

- Find resale candidates and rising/falling prices from saved history, then open live Buy listings.
- Use observed vendor costs for supplies. See net crafting profit, return and break-even prices; search recipes and quote services with markup, labor and minimum charges.
- Save editable watchlists from the Buy page and receive local target alerts after scans.
- Track AH/vendor activity, commissions, trade gold, daily loot and expenses such as repairs, training, respecs, postage and flights.
- Review local-date income, spending, cash flow and costed profit. Filter by transaction type, combine Other expense categories, edit entries and copy CSV.

Existing scanning, combat tooltip prices, stack totals, daily history and labeled Classic disenchant estimates remain included.

Close WoW, replace the addon folder using the **Clean ZIP**, and keep WTF/SavedVariables. Existing data carries forward. **584/584 local Lua 5.1 tests pass**; source, full Git history, docs and validation files are included in the Complete Package.

Prices are asking-price estimates. Unknown costs stay unknown; the ledger does not reconstruct every past transaction. Disenchant outcomes remain unverified for Forever. See the README and user guide for controls and limits.
