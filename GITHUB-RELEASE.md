# MS Market Value 1.2.1

Fixes an issue where WoW Forever’s live host names could split scans from the same PvP market. Earlier scans are picked up when they are still saved and belong to that market. The tooltip counts days with a price for the item.

Close WoW, replace the addon folder with the **Clean ZIP**, and keep WTF/SavedVariables. Run `/msmv diagnostics` to check the saved and recovered days.
