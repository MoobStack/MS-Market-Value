# MS Market Value 1.2.1

Price history now stays together when WoW Forever changes reporting hosts within the same market. The addon also picks up compatible PvP scans that are still saved under older host names.

Close WoW and replace `Interface/AddOns/MSMarketValue` with the folder from the **Clean ZIP**. Keep `WTF/SavedVariables` for your prices, ledger and settings. Run `/msmv diagnostics` to check the saved and recovered days.
